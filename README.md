## Simulazione Spotify responsive
In questa esercitazione ho simulato una **single-page application (SPA)**, utilizzando come esempio la web app di **Spotify**. L'applicazione presenta un layout che include una sidebar, un header principale e un player.
Grazie a questa esercitazione, ho imparato che un approccio **mobile-first** è molto più comodo. Partire con poco spazio e aggiungere elementi man mano offre maggiore flessibilità e consente di eliminare eventuali dettagli non necessari.
